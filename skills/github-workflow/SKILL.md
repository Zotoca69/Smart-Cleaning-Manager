description: Manage scoped GitHub issues, branches, commits and pull requests with traceable approval.

Read ../../MANIFEST.md. Check current branch and affected files. Link issue to bounded branch and PR. Inspect diff and sensitive data before publishing. Maintain one current status block with review revision, findings, owner approval, merge and deployment. Do not merge without recorded owner approval. Update worklog at closure; do not create duplicate backlog records.
