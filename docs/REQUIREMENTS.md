# Requirements — draft
AF01 configurable weekly room schedule, triggered by empty household. AF03 configurable per-room vacuum/mop frequency and profiles; simultaneous operation where supported. On-demand restricted rooms and manual preparation acknowledgement. AF04 presence-aware interruption and resume; guest mode blocks automatic starts/resume. Per-person arrival handling and no-answer behavior remain open. AF09 immediate maintenance notifications where reliable signals exist; configurable repeat interval, clear on resolution, resume eligible blocked jobs. AF11 configurable events and recipients, including missed scheduled cleaning. AF12 admin UI for persistent policies, enable flags, status, validation and manual controls. No household-specific defaults mandated.
DK01 model capability profiles; DK02 validate combinations; DK03 controlled transitions; DK04 readback; DK05 accepted vs verified command; DK06 evidence-aware state; DK07 persistent logical and physical jobs; DK08 explicit resume strategy; DK09 verified room completion; DK10 reapply profile per physical job.
Requirements are research inputs pending detailed acceptance criteria.
