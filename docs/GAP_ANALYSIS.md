# Preliminary gap analysis
Candidates: [Vacuum Orchestrator](https://github.com/hyperfelixations/vacuum-orchestrator), [Vacuum Agent](https://github.com/kingchddg901/Vacuum_Agent). Prior research inspected service definitions, not full runtime code. Orchestrator exposes job/queue, room selection, profile and recovery services; Agent exposes room profile and mapping services. Neither has been installed or acceptance-tested here. Do not infer missing features from missing documentation.
Validate: weekly per-room mode schedule, household presence, per-person arrival policy, interactive interruption, resume of same retained paused task, explicit abort/dock and full-scope new start, persistent task identity and outcome, guest mode, notification recipients, reminder escalation, maintenance recovery, missed schedule, full UI. These are unresolved validation areas, not confirmed absent features. Compose is a candidate, contingent on stable supported APIs, licensing and execution tests.
