# Agent operating instructions
Read MANIFEST.md, current branch/diff, relevant issues and docs/WORKLOG.md before work. The manifest is normative after approval; this draft is subject to review.
Load relevant repository skills explicitly when working in an environment without automatic discovery:
- skills/development-workflow/SKILL.md for every assignment
- skills/github-workflow/SKILL.md for GitHub changes
- skills/independent-review/SKILL.md for review handoff and review
See skills/README.md for planned skills. Do not assume a skill launches a different agent or grants permissions. Follow G1–G4, risk classification, stop rules and separate deployment approval. Never disclose private installation details. Record current status and actual verification; do not merge before owner approval.
